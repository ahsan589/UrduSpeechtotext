# 🎙️ Urdu Audio/Video to Text Converter

This project converts **Urdu language audio or video files** into accurate written text using AI-powered transcription engines like **Whisper (OpenAI)** or **Google Cloud Speech-to-Text**.

---

## ✨ Features

- ✅ Converts **Urdu speech in audio/video** into text
- 📁 Supports audio formats: `.mp3`, `.wav`, `.flac`
- 📹 Supports video formats: `.mp4`, `.mkv` (auto-extracts audio)
- 🧠 Uses **AI models** for high-accuracy transcription
- 🌐 Optional: integrates with **Google Cloud API** or runs **offline with Whisper**
- 📝 Outputs transcription in `.txt` or `.srt` subtitle format
